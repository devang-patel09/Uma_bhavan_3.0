# Uma Bhavan — Client/User Manual

## Login
Open the application and enter the Super Admin username and password. There is no public registration.

## Dashboard
After login, the dashboard shows totals for firms, families, members, Permanent/Nominal members, gender, 18+ male members and collection. Recent receipts, members and activities are also shown.

## Firm Master
Add, search, edit, delete and print firms. A firm cannot be deleted while associated family/member records exist.

## Member Master
Create a Permanent or Nominal family. The system generates M/N codes automatically. Add individual members, with DOB driving automatic age. A family cannot mix Permanent and Nominal members.

## Migration
Open a family, select Migrate, select/create destination firm, choose members to move and confirm. The destination code is generated in the same member category. Remaining members stay in the source family.

## Niyari
Use surname and other filters to find female members. Married and unmarried women are classified using Parental Surname. Print or export the report.

## Receipts
Enter/select an eligible male member aged 18+. Ages 18–45 can use Yuvak Mandal or Samaj; age 46+ can use Samaj only. Select receipt type, review default amount, edit if necessary, generate and print. QR information is encoded into the receipt.

## Reports
Generate member, firm, area, gender, age, member-type, 18+ male, Niyari, receipt, collection, migration and audit reports. Export to Excel/PDF or print.

## Excel Import
Download the relevant template, fill it, upload it, review validation results, resolve errors, preview changes and explicitly confirm the import.

## Backup
Super Admin can manually create and download an encrypted backup.

## Restore
Upload a backup, validate it, confirm restore, allow the system to create a safety backup, then restore.

## Audit
Audit history records important actions and can be reviewed by the Super Admin.
