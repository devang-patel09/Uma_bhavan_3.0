# Incident Response
1. Identify scope.
2. Protect data first.
3. Check `/api/health`, logs and Sentry.
4. Disable unsafe workflows if necessary.
5. Restore service using rollback or forward fix.
6. If data loss is suspected, stop writes and evaluate backups.
7. Communicate status to the Super Admin.
8. Record timeline, cause, impact and corrective action.
